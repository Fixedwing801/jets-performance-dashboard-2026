# Jets Performance Dashboard 2026

This repository contains **published outputs only** from the private Jets Performance Lab.

It does not contain the analysis scripts, raw play-by-play source data, private project files, or GitHub credentials.

The `gh-pages` branch is updated automatically by the private analytics workflow. To publish the site, configure GitHub Pages to deploy from the `gh-pages` branch, root folder.

Published files include the interactive dashboard, selected aggregate CSV reports, and generated charts.
