# Jets Performance Dashboard 2026

This repository contains **published outputs only** from the private Jets Performance Lab.

It does not contain the analysis scripts, raw play-by-play source data, private project files, or GitHub credentials.

The `gh-pages` branch is updated automatically by the private analytics workflow. To publish the site, configure GitHub Pages to deploy from the `gh-pages` branch, root folder.

Published files include the interactive dashboard, selected aggregate CSV reports, and generated charts.


## Data attribution

- FTN charting data is supplied by FTN Data and distributed through nflverse under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Attribute **FTN Data** and **nflverse** when using or redistributing FTN-derived dashboard sections and CSV summaries. See the [FTN charting data dictionary](https://nflverse.r-universe.dev/nflreadr/doc/dictionary_ftn_charting.html).
- The NFL schedule release used for game-completeness checks is distributed by nflverse under CC BY 4.0; attribute nflverse and the underlying schedule source when redistributing derived schedule information.
- FTN pass-specific indicators use matched pass plays as their denominator. Motion, RPO, no-huddle, trick-play and box/backfield measures use all matched run/pass scrimmage plays. Missing observations are not converted to zero.
